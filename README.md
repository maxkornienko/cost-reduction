# Solution-cost-reduction

Проектная работа: снижение операционных затрат федеральной дрогери-сети VitaStore. Цели бизнеса – снизить TCO магазина на 40% за счёт перехода в облако и сократить подключение новой точки с двух недель до пяти дней.

| Задание | Содержание |
|---|---|
| [Task1](Task1/README.md) | Карта бизнес-возможностей (heatmap) и матрица Buy vs Build |
| [Task2](Task2/README.md) | Целевой процесс онбординга магазина (BPMN 2.0) и точка верификации |
| [Task3](Task3/README.md) | Схема AS-IS, целевая облачная архитектура (HLD) со слоем HAL, офлайн-режим |
| [Task4](Task4/README.md) | Расчёт TCO на три года для 100 магазинов, ROI и срок окупаемости |

Диаграммы C4 – PlantUML с локальной копией библиотеки [C4-PlantUML](C4PlantUML/). PNG-картинки генерирует GitHub Actions ([plantuml.yml](.github/workflows/plantuml.yml)).
