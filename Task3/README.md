# Task3. Целевая облачная архитектура

Проверенная схема текущей кассовой зоны и целевая облачная архитектура: тонкий клиент на планшете, слой HAL для разнородного оборудования и офлайн-режим.

## Ключевые решения

- На схеме с вики исправлены семь расхождений: SAP ERP on-premises, ночной FTP вместо real-time REST, разнородные терминалы и базы, люди и ручной путь номенклатуры.
- В магазине из своего оборудования остаются только планшет и фискальный регистратор, терминалы – оборудование банка.
- HAL-агент работает на планшете и даёт кассе единое API для оборудования. Новый терминал подключается новым адаптером, кассовое приложение не меняется.
- В облаке: POS Backend (SaaS), SAP ERP (IaaS), Smart Fulfillment, Promo Engine и SKU Matching (PaaS). Планшет общается только с POS Backend.
- Офлайн: кэш цен обновляется раз в сутки, продажа за наличные, баллы только начисляются, чеки синхронизируются с уникальным идентификатором без дублей.
