# Task4. Расчёт экономической эффективности (TCO)

Расчёт стоимости владения ИТ-инфраструктурой 100 магазинов на три года: сравнение AS-IS и TO-BE, ROI и срок окупаемости.

## Ключевые решения

- Расчёт в относительных единицах: 1 у.е. = 1% годовых ИТ-затрат одного магазина в AS-IS. Считаем только магазины, системы HQ не входят.
- За три года TCO снижается на 31%, после перехода годовые затраты ниже на 49% – цель «−40% TCO магазина» выполнена.
- Проект окупается примерно через 13–14 месяцев, ROI за три года – около 150%.
